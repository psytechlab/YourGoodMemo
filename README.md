# PsychotherapyTrainer

Бот для телеграмма, предоставляющий интерфейс для БЯМ, которая работает в режиме иммитации клиента психотерапевта.

## Установку

```
pip install -r requirenments.txt
```

## Запуск

Сделать `.env` файл из шаблона и заполнить токены. Далее выполнить команду
```
python -m src.main
```

# Anchor Detection — поиск «точек опоры» в Telegram-переписке

ИИ-агент, который читает личную переписку человека и находит в ней **«точки опоры»** — паттерны, связи и события, которые дают ощущение смысла и удерживают в жизни.

---

## Что это такое

«Точка опоры» — конкретный, наблюдаемый паттерн в переписке, указывающий на источник устойчивости. Например:

- **S2** — человек несколько раз упоминает «мы», говорит о совместных делах, зовёт людей — паттерн принадлежности
- **S5** — несколько людей регулярно обращаются к нему за советом или помощью — паттерн «я нужен»
- **D3** — он упоминает одно и то же хобби каждую неделю с прогрессом и вовлечённостью

Агент находит такие паттерны и формирует персональный текст с прямыми цитатами из переписки.

---

## Архитектура

Пятиступенчатый пайплайн на локальных LLM через [Ollama](https://ollama.com) с BERT-предобработкой:

```
Telegram export (result.json)
        │
        ▼

└──────────────────────┬──────────────────────────────┘
                       │ df + sentiment / sentiment_score
        ▼
┌─────────────────────────────────────────────────────┐
│  Stage 1 — Labeler (qwen2.5:7b)                     │

                       │ кандидаты с контекстом
```

## Установка

```bash
# 1. Установить Ollama
# https://ollama.com/download

# 2. Скачать модели
ollama pull qwen2.5:7b-instruct-q4_K_M
ollama pull qwen2.5:14b
ollama pull mistral-nemo:12b

# 3. Установить зависимости Python
pip install pandas requests natasha openpyxl
pip install transformers
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

---

## Запуск

```bash
# Экспортируй переписку из Telegram Desktop:
# Настройки → Экспорт данных → формат JSON

# Запуск на одном или нескольких чатах
python run_multi.py data/result.json
python run_multi.py data/chat1.json data/chat2.json data/chat3.json \
    --output results/profile.json \
    --report results/report.txt

# Отключить BERT-разметку (быстрее, но менее точно)
python run_multi.py data/result.json --no-sentiment
```

На Windows перед запуском:
```powershell
$env:PYTHONIOENCODING = "utf-8"
```

## 8 реализованных точек опоры

| Код | Название | Приоритет |
|-----|----------|-----------|
| S1 | Эмоциональная поддержка и близкие связи | P1 |
| S2 | Принадлежность к сообществу | P1 |
| S5 | «Я нужен» / ответственность за других | P1 |
| D2 | Финансовая безопасность | P1 |
| S3 | Признание и самооценочная поддержка | P2 |
| C1 | Надежда и оптимизм — конкретные планы | P2 |
| D3 | Хобби, увлечения и поток | P2 |
| E2 | Копинг-репертуар и стратегии регуляции | P2 |

Всего запланировано 18 точек опоры в 7 сферах.
